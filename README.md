# Thesis Workspace

This repository is trimmed around the final thesis manuscript in
`ScM-thesis-writing/` and the two simulation pipelines that generate the figures
copied into that manuscript.

## Final Source Of Truth

- `ScM-thesis-writing/main.tex`: final thesis source.
- `ScM-thesis-writing/main.pdf`: compiled thesis PDF.
- `ScM-thesis-writing/Citations.bib`: bibliography used by `main.tex`.
- `ScM-thesis-writing/pdfa.xmpi`: PDF/A metadata used at build time.
- `ScM-thesis-writing/Figures/`: copied PDF figures actually referenced by
  `main.tex`.

The final thesis currently references exactly these six figure files:

- `ScM-thesis-writing/Figures/direct_interval_coverage_examples.pdf`
- `ScM-thesis-writing/Figures/coverage_vs_tau.pdf`
- `ScM-thesis-writing/Figures/length_vs_tau.pdf`
- `ScM-thesis-writing/Figures/coverage_length_tradeoff.pdf`
- `ScM-thesis-writing/Figures/model_comparison_uppertau_tradeoff.pdf`
- `ScM-thesis-writing/Figures/model_comparison_uppertau_interval_examples.pdf`

## Final Code And Results Kept

### `section-1-simulation/`

These are the final scripts used by the thesis main simulation section.

- `00_utils.R`: shared utilities.
- `01_dgp_weibull_ph.R`: Weibull PH data-generating process with finite
  administrative horizon.
- `02_conformal_cox_tau.R`: final main conformal algorithm, now using the
  upper-`tau` interval form `[lower(x), tau]`.
- `03_simulation_section1.R`: one-replicate wrapper around the DGP and the final
  conformal method.
- `04_run_experiments_section1.R`: full factorial simulation driver for the main
  Section 1 study.
- `05_analysis_section1.qmd`: analysis script that generates the four main
  simulation figures.
- `06_render_analysis_section1.R`: HTML report renderer for saved result folders.
- `09_cox_plugin_Tstar.R`: final Cox plug-in comparator for `T* = min(T, tau)`,
  used by the model-comparison study.

Final result folder kept:

- `section-1-simulation/results/main-v2/`
  - Final run used for the thesis "Main Conformal Results" section.
  - Kept contents: raw CSV outputs, derived summaries, final PDF figures, and one
    convenience HTML report snapshot.

Exact run configuration recorded in
`section-1-simulation/results/main-v2/raw/run_config.csv`:

```bash
Rscript section-1-simulation/04_run_experiments_section1.R \
  --tag=main-v2 \
  --n_rep=30 \
  --n=2000 \
  --high_dim_p=9 \
  --alpha=0.1 \
  --B=1500 \
  --seed0=20260213 \
  --sample_n=260

Rscript section-1-simulation/06_render_analysis_section1.R \
  --results_dir=section-1-simulation/results/main-v2 \
  --output_file=section1-analysis-main-v2.html
```

### `playground/model-comparison/`

This folder contains the final expanded baseline comparison used in the thesis.
All six methods now return intervals of the common form `[lower(x), tau]`.

- `00_survreg_working_models.R`: Weibull and log-normal plug-in and conformal
  helpers under the upper-`tau` construction.
- `01_run_model_comparison.R`: final six-method comparison driver.
- `02_analysis_model_comparison.qmd`: analysis script that generates the
  comparison figures and summary tables.
- `03_render_model_comparison.R`: HTML report renderer for saved comparison runs.

Final result folder kept:

- `playground/model-comparison/results/baseline-full-v5-all-upper/`
  - Final run used for the thesis "Expanded Baseline Working-Model Comparison"
    section.
  - Kept contents: raw CSV outputs, derived summaries, final PDF figures, and one
    convenience HTML report snapshot.
  - The coverage-vs-`tau` and length-vs-`tau` PDFs are kept there as useful
    supplementary plots, even though the thesis now only includes the tradeoff and
    direct-interval figures.

Exact run configuration recorded in
`playground/model-comparison/results/baseline-full-v5-all-upper/raw/run_config.csv`:

```bash
Rscript playground/model-comparison/01_run_model_comparison.R \
  --tag=baseline-full-v5-all-upper \
  --n_rep=30 \
  --n=2000 \
  --B=1500 \
  --seed0=20260321 \
  --tau_quantiles=0.70,0.80,0.90,0.99 \
  --wrong_dist=lognormal

Rscript playground/model-comparison/03_render_model_comparison.R \
  --results_dir=playground/model-comparison/results/baseline-full-v5-all-upper \
  --output_file=model-comparison-analysis.html
```

## Cleanup Policy Used Here

The repository intentionally keeps:

- final code paths used by `ScM-thesis-writing/main.tex`,
- final raw and derived result tables behind those figures,
- the copied thesis figure PDFs,
- the older standalone `section-1-writing/` draft,
- background literature under `reference-materials/`.

The repository intentionally removes:

- old smoke tests and exploratory result folders,
- outdated comparison runs that are no longer used,
- duplicate render mirrors and build byproducts,
- thesis figure copies that are no longer referenced by `main.tex`,
- OS metadata files.
